# Интерпретатор учебного языка программирования на C++

Реализация интерпретатора для языка программирования C-подобного синтаксиса. Включает полный конвейер обработки исходного кода: лексический анализ, синтаксический анализ с построением ПОЛИЗ, семантическую проверку и интерпретацию.

## Возможности языка

Интерпретатор поддерживает следующие конструкции:

* **Типы данных:** `int`, `string`, `bool`
* **Объявление и инициализация переменных:** `int a = 5;`
* **Арифметические операции:** `+`, `-`, `*`, `/`, `%`
* **Операции сравнения:** `<`, `>`, `<=`, `>=`, `==`, `!=`
* **Логические операции:** `and`, `or`, `not`
* **Условный оператор:** `if (условие) { ... } else { ... }`
* **Цикл:** `while (условие) { ... }`
* **Ввод/вывод:** `read(a);`, `write("Hello", a);`
* **Блоки кода:** `{ ... }`
* **Комментарии:** `// однострочные` и `/* многострочные */`

## Структура репозитория

* **`interpreter.cpp`** — точка входа, запуск анализа и интерпретации.
* **`LexAnlz.h` / `LexAnlz.cpp`** — лексический анализатор (токенизация, распознавание ключевых слов, чисел, строк, идентификаторов).
* **`StxAnlz.h` / `StxAnlz.cpp`** — синтаксический анализатор (метод рекурсивного спуска, построение ПОЛИЗ, семантические проверки).
* **`POLIZ.h` / `POLIZ.cpp`** — реализация польской инверсной записи (POLIZ) и её интерпретация (стековая машина).
* **`TableOfID.h` / `TableOfID.cpp`** — таблица идентификаторов (хранение переменных, их типов и значений).
* **`info.cpp`, `info1.cpp`** — примеры программ на входном языке.
